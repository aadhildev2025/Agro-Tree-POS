# Agro-Tree-POS

A Point of Sale (POS) system built using React, Vite, and Express.

## Tech Stack

- **Frontend**: React, Tailwind CSS, Vite
- **Backend**: Express.js, Node.js
- **Database**: MongoDB (Mongoose) / SQLite
- **Other Tools**: Chart.js for data visualization, jsPDF for document generation, jsbarcode for barcodes.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- MongoDB (if using MongoDB as database)

### Installation

1. Install all dependencies:
```bash
npm install
```

### Running the Application

Start the development server (runs both the React frontend and Express backend concurrently):

```bash
npm run dev
```

### Available Scripts

- `npm run dev`: Runs both client and server concurrently.
- `npm run server`: Starts only the Express backend server.
- `npm run client`: Starts only the Vite development server for the frontend.
- `npm run build`: Builds the frontend for production.
